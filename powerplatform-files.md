# Power Platform files in the repository

Everything for Power Apps and Power Automate is under `powerplatform/`. Only part of it is source that developers edit and review; the rest is metadata the tools write.

## Source: edit and review

| Path | What | Files |
|---|---|---|
| `powerplatform/canvas-app/Src/*.fx.yaml` | **The app's formulas and controls, one file per screen**: `srcHome`, `srcCapture`, `srcMatchResult`, `srcHistory`, `srcEmployeeList`, `srcSharePointBrowser` | 6 |
| `powerplatform/canvas-app/Src/App.fx.yaml` | App-level settings and `OnStart` (e.g. `gblPageSize`) | 1 |
| `powerplatform/canvas-app/Src/Components/*.fx.yaml` | **Shared components**: `cmpMatchPanel` (register / register unknown), `cmpPager`, `cmpHomeActions` (upload + OCR), `cmpHeader`, `cmpBottomNav`, `cmpEmpModal`, `cmpZoomBar`, `Component1` | 8 |
| `powerplatform/solution/EDSPADelivery/Workflows/*.json` | **The 5 solution flows**: `EDS-ProcessLabel`, `EDS-UploadCaptureImage`, `EDS-SaveUnknownPackage`, `EDS-NotifySelected`, `EDS-SetFileSizeBytes` | 5 |
| `powerplatform/solution/EDSPADelivery/environmentvariabledefinitions/` | Environment variables (SharePoint, Teams and Planner IDs) | 13 |
| `powerplatform/flows/EDS-APIManagement1.json` | **The API gateway flow** (not in the solution) | 1 |

## Generated by the tools: keep, but do not edit by hand

| Path | What |
|---|---|
| `canvas-app/Src/EditorState/`, `Src/Components/*.json` | Studio editor state and component metadata |
| `canvas-app/Entropy/` | IDs and checksums used to rebuild the app exactly. These change on every download and are the main source of noisy diffs. |
| `canvas-app/Other/Src/*.pa.yaml` | A second, read-only copy of the formulas in the newer format. `pac` regenerates it. |
| `canvas-app/DataSources/`, `Connections/`, `pkgs/` | Definitions of data sources, connectors and control packages. They change when someone adds a data source or connector. |
| `canvas-app/CanvasManifest.json`, `ComponentReferences.json`, `ControlTemplates.json`, `Assets/` | App name and version, control templates, images |
| `solution/EDSPADelivery/solution.xml`, `customizations.xml`, `[Content_Types].xml` | Solution header, connection references, packaging |
